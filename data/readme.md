# Data

This project uses the **Olist Brazilian E-Commerce Public Dataset** from Kaggle.

**Source:** https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Files (9 CSVs)

| File | Rows (approx.) | Description |
|---|---|---|
| olist_orders_dataset.csv | 99,441 | Order-level data with timestamps |
| olist_order_items_dataset.csv | 112,650 | Line items with price and freight |
| olist_order_payments_dataset.csv | 103,886 | Payment method and value |
| olist_order_reviews_dataset.csv | 99,224 | Review scores and comments |
| olist_customers_dataset.csv | 99,441 | Customer location data |
| olist_sellers_dataset.csv | 3,095 | Seller location data |
| olist_products_dataset.csv | 32,951 | Product attributes |
| olist_geolocation_dataset.csv | 1M+ | Zip code → lat/lng mapping |
| product_category_name_translation.csv | 71 | Portuguese → English categories |

**Note:** CSVs are not uploaded to this repo due to size. Download from the Kaggle link above and place them in this `data/` folder.
